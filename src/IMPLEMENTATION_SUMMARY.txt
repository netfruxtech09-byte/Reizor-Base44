✅ USER FLOWS:

SELLER WORKFLOW:
  1. Lists ticket for resale
  2. Buyer purchases it
  3. ✅ Wallet credited immediately
  4. Views balance at /my-resale-earnings
  5. Requests payout (method + details)
  6. Admin approves
  7. Admin marks completed
  8. Seller receives funds + confirmation email
  9. Transaction in permanent history

BUYER WORKFLOW:
  1. Finds resale listing
  2. Pays ($listing + $platform_fee)
  3. ✅ New ticket with unique QR code issued
  4. Receives confirmation email
  5. Can view in /my-tickets
  6. Scans QR code at event ✅ gets in
  7. Original seller's old QR fails ✅ can't get in

ADMIN WORKFLOW:
  1. Go to Admin Payouts → "Fan Resale Payouts" tab
  2. See pending payout requests
  3. Review seller, amount, payout method
  4. Click "Approve" → seller notified
  5. Later, click "Mark Completed" → seller gets paid
  6. Wallet balance updates automatically
